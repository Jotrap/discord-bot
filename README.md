# Discord Bot - Alertas Diarias

Bot de Discord que envía alertas diarias a las 7:00 PM (hora Perú).

## Instalación

1. Clona este repositorio
2. Instala las dependencias: `pip install -r requirements.txt`
3. Configura tu token en las variables de entorno

## Uso

Ejecuta el bot con: `python main.py`
